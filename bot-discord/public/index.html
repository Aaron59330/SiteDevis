SERVEUR · 16

Salon anonyme.

Les messages sont republiés par le bot sans afficher le pseudo de leur auteur.

Messages anonymes

Choisis un salon où les messages seront relayés sous le nom du bot.

Tous les messages écrits par des membres dans ce salon seront republiés sans leur nom.

Le bot republie le texte et les fichiers joints, puis supprime le message original. Il doit avoir les permissions Envoyer des messages, Gérer les messages et Joindre des fichiers dans ce salon. Les messages du bot sont ignorés.

Comment ça marche

Les membres écrivent normalement dans le salon sélectionné. Le bot relaye leur message sans signature ni mention de l’auteur.

04

À savoir

Le bot efface l’original seulement après avoir vérifié ses permissions. Les fichiers sont repostés avec un nom neutre.

MODÉRATION · 06

Protection.

Modération automatique : spam, liens, invitations, mentions de masse, majuscules et mots interdits.

Protection automatique

Active la protection, puis choisis les règles à appliquer.

Anti-spamBloque les membres qui envoient trop de messages trop vite.
Anti-répétitionSupprime le même message envoyé plusieurs fois de suite.
Anti-invitationsSupprime les invitations vers d’autres serveurs Discord (discord.gg…).
Anti-liensSupprime les liens, sauf ceux des sites autorisés.
Anti-mentions de masseBloque les messages qui mentionnent trop de membres ou de rôles.
Anti-majusculesSupprime les messages écrits presque entièrement en majuscules.
Mots interditsSupprime les messages qui contiennent un mot de la liste (accents et majuscules ignorés).

Sanction et exceptions

Ce qui se passe quand une règle est enfreinte, et qui n’est jamais concerné.

Chaque infraction y est signalée. Elles sont toujours visibles dans le Journal.
Ces rôles ne sont jamais sanctionnés. Les membres qui peuvent gérer les messages sont toujours ignorés.
La protection ne s’applique pas dans ces salons.

Permissions du bot

Le bot doit pouvoir gérer les messages pour supprimer, et exclure temporairement des membres pour la sanction d’exclusion. Son rôle doit être au-dessus de ceux des membres sanctionnés.

COMMUNAUTÉ · 09

Niveaux.

Les membres gagnent de l’expérience en écrivant et débloquent des rôles.

Expérience

Réglages du gain d’XP et des annonces de niveau.

/niveau/classement
Évite de gagner de l’XP en spammant (60 s conseillé).
Variables : {user} mention · {pseudo} nom · {level} nouveau niveau · {server}

Rôles récompenses

Un rôle donné automatiquement à un niveau.

Cumuler les récompensesActivé : le membre garde tous les rôles gagnés. Désactivé : seul le rôle du plus haut niveau est gardé.

Exceptions

Aucune XP dans ces salons ou pour ces rôles.

Classement

Les 50 membres les plus actifs.

Choisis un serveur.

Comment ça marche ?

Chaque message rapporte entre XP min et max, au plus une fois par délai. Il faut 100 XP pour le niveau 1, puis un peu plus à chaque niveau (même courbe que les grands bots).

Rôles récompenses

Le rôle du bot doit être au-dessus des rôles à donner, avec la permission Gérer les rôles.

COMMUNAUTÉ · 12

Réponses automatiques.

Le bot répond tout seul quand un mot ou une phrase est écrit.

Déclencheurs

Jusqu’à 50 réponses. Exemple : « ip » → « play.monserveur.fr ».

Variables dans la réponse : {user} mention · {pseudo} nom · {server} serveur · {memberCount} nombre de membres · {channel} salon

Types de déclenchement

Contient : le mot apparaît dans le message. Exact : le message est exactement ce texte. Commence par : le message débute ainsi. Majuscules ignorées, 5 s minimum entre deux réponses identiques.

Le bot ne peut pas donner un rôle

Dans Paramètres du serveur → Rôles, glisse le rôle d’AERO BOT au-dessus du rôle à donner, et vérifie la permission Gérer les rôles.

« Je ne peux pas exclure ce membre »

Le membre a un rôle égal ou supérieur à celui du bot (ou au tien), ou le bot n’a pas la permission Exclure temporairement des membres.

Un compteur ne se met pas à jour

Discord n’autorise que 2 renommages de salon par 10 minutes : la mise à jour arrive dans les 6 minutes. Vérifie que le bot peut Gérer les salons.

Les membres de l’équipe sont sanctionnés par la Protection

Les membres qui peuvent gérer les messages ne sont jamais sanctionnés. Pour d’autres rôles, ajoute-les dans Protection → Rôles ignorés.

Où voir ce qui s’est passé ?

Dans le Journal : arrivées, départs, messages supprimés, sanctions, tickets, actions du panneau, avec recherche et filtres. Conservé 90 jours.
