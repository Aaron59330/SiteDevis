COMMUNAUTÉ · 04

Salon anonyme.

Les messages sont republiés par le bot sans afficher le pseudo de leur auteur.

◌

Messages anonymes

Choisis un salon où les messages seront relayés sous le nom du bot.

Tous les messages écrits par des membres dans ce salon seront republiés sans leur nom.
ⓘ

Le bot republie le texte et les fichiers joints, puis supprime le message original. Il doit avoir les permissions Envoyer des messages, Gérer les messages et Joindre des fichiers dans ce salon. Les messages du bot sont ignorés.

◌

Comment ça marche

Les membres écrivent normalement dans le salon sélectionné. Le bot relaye leur message sans signature ni mention de l’auteur.

04

À savoir

Le bot efface l’original seulement après avoir vérifié ses permissions. Les fichiers sont repostés avec un nom neutre.

OUTILS DU SERVEUR · 04

Commandes.

Active uniquement les outils que tu veux rendre disponibles sur ce serveur.

/clearmessages nombre

Nettoyer le salon

Supprime de 1 à 100 messages récents. Discord ne permet pas la suppression groupée des messages de plus de 14 jours.

Membre et bot : Gérer les messages
/slowmode secondes

Mode lent

Règle un délai de 0 à 21 600 secondes entre les messages. La valeur 0 désactive le mode lent.

Membre et bot : Gérer les salons
/userinfo [membre]

Infos d’un membre

Affiche son identifiant, la date de création du compte, sa date d’arrivée et ses rôles.

Réservée aux membres du serveur
/serverinfo

Infos du serveur

Affiche le nombre de membres, le propriétaire, la date de création et l’identifiant du serveur.

Réservée aux membres du serveur
/avatar [membre]

Voir un avatar

Affiche en grand l’avatar de la personne choisie ou le tien si aucun membre n’est indiqué.

Réservée aux membres du serveur
ⓘ

Les commandes de modération apparaissent uniquement aux membres qui ont la permission requise. Après l’enregistrement, Discord peut prendre quelques secondes pour afficher les commandes activées.
