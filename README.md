# Mes Devis

Petit site pour créer, suivre et imprimer des devis. Aucune installation : **double-cliquez sur `index.html`** (Chrome, Edge, Firefox, Safari).

- Clients, catalogue de prestations, logo, numérotation automatique
- TVA par ligne (ou micro-entreprise sans TVA), remise, acompte
- Aperçu en direct, impression / export PDF (bouton « Imprimer », choisir « Enregistrer au format PDF »)
- Données enregistrées dans votre navigateur ; export/import de sauvegarde en JSON
